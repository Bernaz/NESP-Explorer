# SEQ Land for Wildlife Explorer

Interactive explorer of the 2024 and 2026 Land for Wildlife member surveys in South East Queensland (NESP project).

Page: https://bernaz.github.io/NESP-Explorer/

The page is password-protected: the survey data are under UTAS ethics approval H0027729, so the whole page is
encrypted (AES-256-GCM, key from the team password by PBKDF2-SHA256) and only opens in the browser once the
password is entered. Ask the project lead for the password.
